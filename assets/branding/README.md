## Français

Le logo rétro original du 2 octobre 2026 est conservé sans modification dans [pmkb-logo-original.png](pmkb-logo-original.png). Nom du fichier source : « Logo rétro PMKB et Kobo souriant.png ».

Les neuf photos originales du démontage sont conservées dans [docs/images/disassembly/originals](../../docs/images/disassembly/originals/README.md), en complément des illustrations déjà utilisées par le guide.

Les déclinaisons bannière, icône, monochrome et SVG avaient été proposées ; aucun fichier distinct de ces déclinaisons n'a été retrouvé. Le PNG original est actuellement utilisé comme visuel d'accueil dans les deux README du projet.

Les empreintes SHA-256 des dix fichiers archivés figurent dans [visuals.sha256](../visuals.sha256). Depuis la racine du dépôt : `sha256sum -c assets/visuals.sha256`.

## English

The original retro logo from October 2, 2026 is preserved unchanged in [pmkb-logo-original.png](pmkb-logo-original.png). Original source filename: “Logo rétro PMKB et Kobo souriant.png”.

Nine original disassembly photos are preserved in [docs/images/disassembly/originals](../../docs/images/disassembly/originals/README.md), alongside the illustrations already used in the guide.

Banner, icon, monochrome and SVG variants had been proposed; no separate files for those variants were recovered. The original PNG is currently used as the welcome artwork in both project READMEs.

SHA-256 checksums for all ten archived files are in [visuals.sha256](../visuals.sha256). From the repository root: `sha256sum -c assets/visuals.sha256`.
