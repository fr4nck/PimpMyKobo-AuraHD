# PimpMyKobo-AuraHD

Resurrection and modernization of the Kobo Aura HD.

## Target

- Kobo Aura HD / N204
- Freescale i.MX507
- 512 MiB RAM
- Netronix hardware platform
- Minimal Linux userspace
- KOReader

## Goal

Build a lightweight, independent reading system for the Kobo Aura HD
without relying on Kobo services.
